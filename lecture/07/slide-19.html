Промпт · учебный протокол
Отвечай только по фрагментам ниже.
После каждой фразы ставь [id] фрагмента.
Если ответа во фрагментах нет — так и скажи.

[kr-demo@2026#3.3.3] (учебные рекомендации, 2026)
Препарат A: СКФ 45–59 — 75 % дозы;
СКФ 30–44 — 50 % дозы; СКФ < 30 — не применять.

[kr-demo@2026#3.3.2] (учебные рекомендации, 2026)
Не использовать креатинин без расчёта СКФ.

Вопрос: какая доза препарата A при СКФ 41?
Инструкция

Только по фрагментам

Модель не должна дополнять ответ своей памятью — она может помнить старую редакцию.

Фрагменты

С id и версией

Без id ссылаться не на что. Без версии врач не поймёт, какую редакцию цитируют.

Отказ

Разрешён явно

«Во фрагментах нет» — правильный ответ, если поиск ничего не нашёл. Иначе модель придумает.
