Каркас P-0042

Сквозной каркас курса: агент готовит справку к онкологическому консилиуму по вымышленной пациентке P-0042. Каждая лекция добавляет или заменяет одну деталь, остальное продолжает работать. Всё на Python; 42 теста идут без сети и без модели.

github.com/EdwFa/MAS/tree/main/P-0042

Запуск

git clone https://github.com/EdwFa/MAS && cd MAS/P-0042
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python check_env.py          # Python, пакеты, данные, тесты, локальная модель
python run.py "Посчитай СКФ и найди, что рекомендации говорят о дозах"
python run_eval.py           # прогон на наборах оценки
pip install -r requirements-ui.txt
streamlit run ui/app.py      # интерфейс врача, работает без модели

Адрес и имя локальной модели — в переменных P0042_BASE_URL и P0042_MODEL. Адрес может быть только локальным.

Случай

Женщина 67 лет, рак левой молочной железы, HER2 3+, ER и PR отрицательные, Ki-67 не выполнен; cT2N1M0. Сахарный диабет и гипертензия, метформин и лизиноприл, аллергия на йодконтраст. Креатинин 124 мкмоль/л, СКФ 41. Консилиум в пятницу 20.11; агент собирает пакет с понедельника. Ещё четыре пациента — для краевых случаев: другой диагноз, нет креатинина, 17 лет, однофамилица.

В данные заложены ловушки: спор дат консилиума, устаревшая запись, креатинин в другой единице, дубль анализа, инъекция в скане выписки, повтор уведомления лаборатории. Полная таблица — data/README.md.
