Маршрутизация агентов

Маршрутизатор решает, куда пойдёт случай дальше: ждать, собирать пакет или сразу к врачу. Задание проверяет устройство, а не качество модели: классификатор можно заменить заглушкой.

Что сделать

ROUTES = {"wait", "assemble", "doctor_now"}

def route(case, classify, threshold=0.8):
    if case.get("red_flags"):            # правило раньше модели
        return "doctor_now", "правило: красный флаг"
    label, p = classify(case)            # классификатор или LLM
    if label not in ROUTES:              # ветки нет в коде
        return "doctor_now", f"неизвестная ветка {label}"
    if p < threshold:                    # не уверен — к человеку
        return "doctor_now", f"неуверенно: {label} {p:.2f}"
    return label, f"{label} {p:.2f}"
  • Реализовать route по слайду 12 лекции 3 в файле router.py.
  • Тесты: случай с красным флагом уходит к врачу до вызова классификатора; ветка, которой нет в коде, уходит к врачу; уверенность 0,6 при пороге 0,8 уходит к врачу; уверенная ветка проходит.
  • Каждое решение возвращает причину — она идёт в трассу.
