Идемпотентная запись в карту

def chart_write(case_id, step, resource, fhir, ledger):
    """Запись в карту, которую безопасно повторить."""
    key = f"{case_id}/{step}"           # одна запись на шаг
    if (done := ledger.get(key)):       # уже писали —
        return done                     # вернуть то же
    resource["identifier"] = [
        {"system": "urn:mas:write", "value": key}]
    ref = fhir.create(                  # условное создание FHIR:
        resource,                       # сервер не создаст дубль
        if_none_exist=f"identifier=urn:mas:write|{key}")
    ledger.put(key, ref)                # после ответа сервера
    return ref
Ключ

Случай и шаг

Стабилен при любом повторе. Temporal советует то же: id запуска и id шага.

Два слоя

Журнал и сервер

Журнал отвечает быстро. Условное создание (If-None-Exist) спасает, если процесс упал между записью и журналом.

Пауза

Только после подписи

chart_write по-прежнему с политикой «спросить». Идемпотентность не отменяет права.
