Лекция 6. MCP, подключение ИИ-приложений к внешним системам17

Практические применения MCP

Первые четыре случая из девяти. Модель подключается к базе, к программам картинки и звука, к чужим API и к точному месту в тексте.

01

Базы данных

Агент обращается к базе обычными словами: читает текущие записи, собирает отчёт, обновляет строку. Для Google BigQuery это делает MCP Toolbox.

02

Картинка, видео, голос

Через MCP Tools для Genmedia агент собирает цепочку: Google Imagen рисует, Google Veo снимает видео, Chirp 3 HD говорит, Google Lyria пишет музыку.

03

Внешние API

Один порядок для любого внешнего API: погода сейчас, цена акции, письмо, учёт клиентов.

04

Точный фрагмент

Агент читает текст и достаёт фрагмент, цифру или утверждение под вопрос. Обычный поиск отдал бы документ целиком.

Подключение одно. Меняется служба: база, картинка и звук, чужой API, нужное место в тексте.
