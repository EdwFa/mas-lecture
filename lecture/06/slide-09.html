MCP и вызов функции

Оба способа выводят модель за текст. Вызов функции просит один инструмент. MCP задаёт общий порядок для многих служб и разных моделей.

Вызов функции

  1. 01Модель обращается к одному заранее описанному инструменту. Здесь «инструмент» и «функция» — одно и то же.
  2. 02Связь одна к одной: по намерению пользователя модель оформляет просьбу.
  3. 03Программа выполняет её и возвращает результат модели.
  4. 04Порядок свой у каждого поставщика модели.

MCP

  1. 01Открытый порядок: модель находит внешние возможности и пользуется ими.
  2. 02Один и тот же инструмент доступен разным совместимым моделям.
  3. 03Старую службу оборачивают и не переписывают. Она работает как раньше.
  4. 04Модель собирает из таких служб новое приложение и направляет их совместную работу.

Вызов функции — просьба к одному инструменту. MCP — общий способ связать много служб с разными моделями.
