Ресурсы и заготовки

@mcp.resource("fhir://Observation/{obs_id}")
def observation(obs_id: str) -> dict:
    """Наблюдение из учебного FHIR. Только чтение."""
    return FHIR.read("Observation", obs_id)

@mcp.prompt
def renal_check(case_id: str) -> str:
    """Проверка функции почек перед консилиумом."""
    return (f"Для случая {case_id}: найди последний креатинин "
            "в fhir://Observation, посчитай egfr и укажи "
            "дату анализа и ссылку на запись.")

Заготовка

Сценарий кафедры

Порядок проверки почек пишет врач, а не модель. Заготовку выбирает человек в интерфейсе.

Только чтение

Ресурс ничего не меняет

Всё, что меняет карту, — инструмент с политикой «спросить».
