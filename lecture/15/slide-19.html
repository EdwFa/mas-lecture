Лекция 15. Передача между агентами19

Контракт передачи

contracts/lab_summary.json
{
  "type": "object",
  "required": ["type", "case", "status", "items", "open"],
  "additionalProperties": false,
  "properties": {
    "type":   {"const": "lab_summary"},
    "case":   {"type": "string", "pattern": "^P-[0-9]{4}$"},
    "status": {"enum": ["ok", "partial", "failed"]},
    "items":  {"type": "array", "items": {
      "type": "object",
      "required": ["marker", "value", "source"],
      "additionalProperties": false,
      "properties": {
        "marker": {"enum": ["HER2", "ER", "PR", "Ki-67"]},
        "value":  {"type": "string", "maxLength": 16},
        "source": {"type": "string", "pattern": "^Observation/"}}}},
    "open":   {"type": "array",
               "items": {"type": "string", "maxLength": 200}}
  }
}
required

Что не может пропасть

Пять полей артефакта и три поля каждого значения. Пустой список — можно, отсутствующий — нельзя.

additionalProperties

Ничего лишнего

Субагент не добавит поле «рекомендация». Схема — граница его полномочий.

source

Ссылка обязательна

Значение без записи FHIR не принимается. Сборщик не сможет выдать реплику за факт.
