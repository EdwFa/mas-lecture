Лекция 13. Harness агента16

Имя, описание, схема

{
  "name": "fhir_read",
  "description": "Читает один ресурс FHIR
    учебного сервера по типу и id.
    Только чтение.",
  "input_schema": {
    "type": "object",
    "properties": {
      "resourceType": {
        "enum": ["DocumentReference",
                 "Observation", "Condition",
                 "Encounter"] },
      "id": { "type": "string" }
    },
    "required": ["resourceType", "id"],
    "additionalProperties": false
  }
}
01

Имя

По нему модель зовёт инструмент. Одно имя — одно действие.

02

Описание

По нему модель решает, звать ли. Это промпт, и его пишут так же тщательно.

03

Схема

По ней harness сверяет аргументы до исполнения.

additionalProperties: false — поле, которого нет в схеме, не исполняется «по смыслу».
