Код: цикл с бюджетом

def answer_loop(question, retrieve, rewrite, judge, llm,
                max_steps=3):
    """Ищем, пока найденного не хватит или не кончится бюджет."""
    query, context, trace, seen = question, [], [], set()
    for step in range(1, max_steps + 1):
        found = retrieve(query)
        verdict = grade(question, found, judge)
        trace.append({"step": step, "query": query,
                      "verdict": verdict, "found": len(found)})
        if verdict != "incorrect":
            context += found
        if verdict == "correct":
            break
        seen.add(query)
        query = rewrite(question, query)
        if query in seen:              # переписал в то же самое
            break
    if not context:
        return {"answer": "в рекомендациях не найдено",
                "status": "not_found", "trace": trace}
    return {"answer": llm(ANSWER.format(question=question,
                                        context=context)),
            "status": verdict, "trace": trace}
Три останова

Верно, бюджет, повтор

Цикл кончается, когда найденного хватило, когда кончились шаги или когда переписанный запрос уже был.

status

Честный итог

«ambiguous» уходит в пакет пометкой: ответ по неполным данным. Врач видит это, а не только текст.

trace

Каждый шаг

Запрос, оценка, сколько найдено. По трассе видно, где цикл тратил шаги.
