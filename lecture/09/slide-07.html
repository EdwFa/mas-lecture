Лекция 9. Оркестрация RAG07

Код: маршрут по сложности

import json
from jsonschema import validate, ValidationError

ROUTE = {"type": "object", "required": ["kind", "confidence"],
         "properties": {
             "kind": {"enum": ["chart_fact", "single", "multi"]},
             "confidence": {"type": "number",
                            "minimum": 0, "maximum": 1}},
         "additionalProperties": False}
SAFER = {"chart_fact": "single", "single": "multi", "multi": "multi"}

def route_question(question, llm, threshold=0.8):
    """Путь по сложности; при сомнении — на ступень тщательнее."""
    try:
        out = json.loads(llm(CLASSIFY.format(question=question)))
        validate(out, ROUTE)
    except (ValueError, ValidationError):
        return "multi"                 # не разобрали — самый полный путь
    if out["confidence"] < threshold:
        return SAFER[out["kind"]]
    return out["kind"]
Схема

Три пути и уверенность

Модель не может придумать четвёртый путь. Ответ вне схемы — самый полный путь, а не ошибка.

SAFER

Ступень вверх

Неуверенность сдвигает вопрос на более тщательный путь, никогда — на более простой.
