Лекция 9. Оркестрация RAG12

Код: оценка найденного

def grade(question, chunks, judge, hi=0.7, lo=0.3):
    """Хватает ли найденного: correct, ambiguous, incorrect."""
    best = max((judge(question, c["text"]) for c in chunks),
               default=0.0)
    if best >= hi:
        return "correct"
    if best >= lo:
        return "ambiguous"
    return "incorrect"
Лучший кусок

Достаточно одного

Если хотя бы один кусок прямо отвечает на вопрос — можно отвечать. Остальное решает отбор.

Пусто

Тоже incorrect

Ничего не нашли — оценка 0. Это не ошибка программы, а сигнал переписать запрос.

Из измерений

hi и lo подбирают на 30 вопросах кафедры, а не берут из статьи.
