Лекция 14. Скиллы агента06

Библиотека скиллов

Одна папка — один скилл. Все скиллы лежат рядом в общей папке skills/: у практикума их три.

skills/
├── package-check/           проверка пакета
│   ├── SKILL.md             name: package-check
│   ├── scripts/check.py
│   └── references/fields.md
├── package-build/           сборка пакета
│   └── SKILL.md             name: package-build
└── lab-summary/             анализы и маркеры
    └── SKILL.md             name: lab-summary
01

Один SKILL.md на папку

name совпадает с именем папки, поэтому два скилла в одной папке не уживутся.

02

Имена уникальны

Две папки с одним name — конфликт. Harness должен поймать его при старте.

03

Без вложенности

scan ищет skills/*/SKILL.md. Подпапки внутри скилла — его scripts/, references/, assets/.

04

Без общих файлов

Ссылки только внутри своей папки. Общий код — инструмент harness, а не чужой scripts/.

Модель видит каталог из трёх строк и выбирает один скилл. Тело читают только у него. Где лежит skills/ — решает клиент.
