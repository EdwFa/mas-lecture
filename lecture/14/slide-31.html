Лекция 14. Скиллы агента31

Скилл в эксплуатации

Публикация — не конец. Скилл живёт в клинике, и его поведение видно только в трассах.

Черновик

Два экземпляра модели, тесты до скилла.

Ревью

Pull request, чек-лист, второй человек.

Версия

metadata.version и коммит в трассе.

Выкатка

Одно отделение, потом остальные.

Наблюдение

Трассы и правки врачей.

Считаем по трассам

Метрики

  • доля запросов, где скилл сработал
  • ложные срабатывания: прочитан, но не к месту
  • ответы со скиллом, которые врач поправил
  • ошибки скриптов: код 2
Петля

Правка → тест

  • фраза, на которой скилл не сработал, — в тесты срабатывания
  • пакет, где врач поправил ответ, — в тесты работы
  • новая версия — только после прогона
Вывод из употребления

Без потерь

  • убрать имя из каталогов агентов
  • папку оставить в git
  • старые трассы читаются по версии

Как выкатывать релиз по отделениям и что смотреть каждый день — лекция 18.
