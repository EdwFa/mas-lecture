Лекция 14. Скиллы агента17

Много скриптов: как выбирают

Фрагмент SKILL.md
## Скрипты
| Скрипт      | Когда                   | Выход            |
|-------------|-------------------------|------------------|
| check.py    | всегда, шаг 2           | ok, problems     |
| dates.py    | в problems — две даты   | даты и источники |
| fhir_ref.py | ссылка не открылась     | тип, id, найдена |

## Шаги
2. Запусти scripts/check.py work/package.json
3. Если в problems «две даты» —
   запусти scripts/dates.py work/package.json
   и вынеси обе даты в open_questions.
4. Если ссылка не открылась —
   запусти scripts/fhir_ref.py с этой ссылкой.
Выбирает

Модель — по телу

Содержимое scripts/ в окно не попадает. Модель знает только те скрипты, что названы в SKILL.md.

Решает

Условие в шаге

«Если… — запусти…»: модель не выбирает, а следует шагу. Много скриптов — одна точка входа run.py с подкомандами.

Пускает

Harness

Только scripts/ этого скилла и файлы случая. Строже — список из SKILL.md: подложенный файл не запустится.

Скрипт, не названный в SKILL.md, для модели не существует. Десяток скриптов для разных задач — повод разделить скилл.
