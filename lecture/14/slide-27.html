Лекция 14. Скиллы агента27

Правила для клиники

01

Только свой репозиторий

Скиллы курса и кафедры лежат в git. Публичные каталоги — для чтения и идей, не для установки.

02

Ревью как код

Скилл меняется через pull request. Читают тело, скрипты, description и allowed-tools: что скилл одобряет себе без вопроса.

03

Права не меняются

Таблица прав из лекции 13 действует на всё, что попросил скилл. chart_write — по-прежнему «спросить».

04

Песочница

Скрипты скилла — без сети и только внутри папки случая. Ключи — вне окна и вне песочницы.

05

Версии

metadata.version и коммит. В трассе — какая версия скилла сработала.
