Скрипт вместо слов

scripts/check.py
"""Проверка обязательных полей пакета к консилиуму."""
import json, sys

REQUIRED = ["case_id", "diagnosis_ref", "imaging_ref",
            "histology_ref", "board_date", "open_questions"]

def check(pkg):
    problems = [f"нет поля {f}" for f in REQUIRED
                if pkg.get(f) in (None, "")]
    for f in ("diagnosis_ref", "imaging_ref", "histology_ref"):
        ref = pkg.get(f, "")
        if ref and "/" not in ref:
            problems.append(f"{f}: не ссылка FHIR вида Тип/id")
    return problems

if __name__ == "__main__":
    with open(sys.argv[1], encoding="utf-8") as fh:
        problems = check(json.load(fh))
    print(json.dumps({"ok": not problems, "problems": problems},
                     ensure_ascii=False))
    sys.exit(1 if problems else 0)
Правило

Проверяемое — в код

Есть ли поле — вопрос для кода, а не для модели. Скрипт ответит одинаково тысячу раз.

Выход

JSON в stdout

Модель читает результат как наблюдение. Код возврата 1 — тоже сигнал для harness.

Связь с лекцией 13

Скрипт или хук

Если проверка нужна всегда — это хук перед ответом. Если по запросу врача — скилл со скриптом.
