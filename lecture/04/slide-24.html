Лекция 4. Инструменты, планирование, ансамбли24

Выводы

01

Инструмент

Модель возвращает имя и аргументы; исполняет оркестратор; результат — наблюдение.

02

Описание

Имя, назначение, схема аргументов. По ним модель выбирает, по ним код проверяет.

03

Проверки

Имя в реестре, аргументы по схеме, права. Отказ и ошибка — тоже наблюдения.

04

Правило числа

Нет строки в наблюдении — нет числа в ответе. Расчёт делает инструмент.

05

План

Шаги из списка кафедры; перепланирование — по событию и из готовых веток.

06

Ансамбль

Делить задачу между агентами — когда нужно. Как решить, что нужно, — лекция 15.
