Функция и инструмент

Паттерн выводит модель за пределы обучающих данных. Function calling соединяет её рассуждение с внешними возможностями.

Что это открывает

  1. 01Актуальная информация, которой нет в обучающих данных.
  2. 02Вычисления, которые модель не выполняет внутри себя.
  3. 03Работа с данными пользователя.
  4. 04Действия во внешнем мире.

Инструмент шире функции

  1. 01Вызов функций — заранее описанный код.
  2. 02Инструмент может быть конечной точкой API или запросом к базе.
  3. 03Инструментом бывает поручение другому агенту.
  4. 04Основной агент отдаёт анализ агенту-аналитику или читает базу знаний через API.

В этих терминах агент — оркестратор ресурсов и других агентов.
