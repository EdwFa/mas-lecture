Лекция 4. Инструменты, планирование, ансамбли05

Описание инструмента

TOOLS = [
  {"name": "lab_reference",
   "description": "Справочник исследований: состав и "
                  "референсы по коду или названию.",
   "input_schema": {"type": "object",
     "properties": {"study": {"type": "string"}},
     "required": ["study"], "additionalProperties": False}},
  {"name": "lab_result",
   "description": "Результат пациента: значение показателя "
                  "по идентификатору случая.",
   "input_schema": {"type": "object",
     "properties": {"case_id": {"type": "string"},
                    "test": {"type": "string"}},
     "required": ["case_id", "test"],
     "additionalProperties": False}},
  {"name": "chart_write",
   "description": "Запись текста в карту. Только после "
                  "подтверждения врача.",
   "input_schema": {"type": "object",
     "properties": {"case_id": {"type": "string"},
                    "text": {"type": "string"}},
     "required": ["case_id", "text"],
     "additionalProperties": False}}]
name

Глагол и объект

Модель выбирает по имени и описанию. «lab_result», а не «tool_2».

description

Когда звать

Что делает и чем отличается от соседа: справочник — норма для всех, результат — число пациента.

input_schema

Аргументы с типами

required и additionalProperties: false — проверку аргументов делает код, а не надежда.
