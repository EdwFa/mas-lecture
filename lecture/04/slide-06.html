Пример — агент взаимодействия с МИС

Взаимодействие с базами данных и API — запросы, обновления и другие операции со структурированными данными.

Агент извлекает лабораторные исследования из медицинской информационной системы (МИС).

Инструменты — API-вызовы, чтобы проверить исследование, узнать его статус или забрать результат.

  1. 01Пользователь спрашивает: «ОАК Ивановой Ангелины Ивановны?»
  2. 02Модель вызывает API лабораторных исследований.
  3. 03Инструмент возвращает подробный результат ОАК пациента Ивановой А.И. (Иванова Ангелина Ивановна).
