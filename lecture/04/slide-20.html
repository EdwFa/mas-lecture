Лекция 4. Инструменты, планирование, ансамбли20

Код: план из разрешённых шагов

ALLOWED = {"read_problems", "read_meds", "read_lab",
           "read_imaging", "assemble", "check", "ask_doctor"}

def run_plan(plan, steps, state):
    unknown = [s for s in plan if s not in ALLOWED]
    if unknown:
        raise ValueError(f"шаги вне списка: {unknown}")
    for name in plan:
        result = steps[name](state)
        state["trace"].append((name, result.get("status")))
        if result.get("status") == "event":     # что-то изменилось
            return {"status": "replan", "after": name,
                    "reason": result["reason"]}
        state.update(result.get("data", {}))
    return {"status": "done", "state": state}
ALLOWED

Список кафедры

Модель может предложить порядок, но только из разрешённых шагов. Шаг вне списка — ошибка до начала работы.

event

Повод перепланировать

Исполнение останавливается и говорит, после какого шага и почему.

trace

Путь записан

Каждый шаг — строка трассы. Так проверяют, что план исполнен, а не пересказан.
