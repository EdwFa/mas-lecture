П. 1.2. Сценарии одного паттерна

Цепочка промптов режет задачу на последовательные шаги. В главе семь сценариев.

СценарийЦепочка
Контур обработки информации Текст → суммаризация → сущности → база → отчёт
Ответы на сложные вопросы Подзадачи → исследование каждой → синтез ответа
Извлечение и трансформация данных Поля → проверка → условный промпт → внешний инструмент
Генерация контента Идеи → план → разделы → редактура
Разговорные агенты с состоянием Интент и сущности → состояние диалога → следующий промпт
Генерация и улучшение кода Псевдокод → код → проверка → переписывание → тесты
Мультимодальные рассуждения Текст изображения → подписи → таблица
