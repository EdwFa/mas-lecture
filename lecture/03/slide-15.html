Код: параллельное чтение

import asyncio

async def read_all(case, readers, timeout=60):
    async def one(name, read):
        try:
            return name, await asyncio.wait_for(read(case),
                                                timeout)
        except asyncio.TimeoutError:
            return name, {"status": "failed",
                          "reason": f"таймаут {timeout} с"}
    pairs = await asyncio.gather(
        *(one(n, r) for n, r in readers.items()))
    return dict(pairs)      # ждём всех; упавший — с причиной
gather

Барьер

Возвращает, когда закончились все части — успешно или по таймауту.

wait_for

Таймаут на каждую часть

Один медленный источник не задерживает сводку дольше предела.

Независимость

Части не читают друг друга

Параллельно идёт только то, что не зависит от результатов соседей. Иначе это цепочка.
