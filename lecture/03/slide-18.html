def refine(draft, write, critic, checklist, max_rounds=2):
    for _ in range(max_rounds):
        remarks = critic(draft, checklist)   # только пакет и перечень
        if not remarks:
            return draft, []
        draft = write(draft, remarks)
    return draft, critic(draft, checklist)   # остаток — врачу

Предел в коде

Два круга. После них цикл не продолжается, что бы ни сказал критик.

Возврат

Пакет и остаток

Врач получает и черновик, и замечания, которые не сняты. Ничего не прячем.

Перечень

Четвёртый пункт — спор

Спор дат — пункт перечня, а не стиль. Его критик обязан проверить.
