Код: предложение вместо записи

from uuid import uuid4

def propose_instruction(store, current, conversation, llm):
    """Агент предлагает правку, но не применяет её."""
    draft = llm(PROPOSE.format(instructions=current,
                               conversation=conversation))
    pid = f"p-{uuid4().hex[:8]}"
    store.put(("instructions", "proposals"), pid, {
        "old": current, "new": draft, "status": "on_review"})
    return pid

def active_instructions(store):
    """Агент читает только принятую версию."""
    item = store.get(("instructions", "active"), "agent")
    return item.value["text"]
Разные папки

proposals и active

Предложения и действующие инструкции лежат отдельно. Агент пишет в первую, читает из второй.

Кто переносит

Человек

Из proposals в active переносит ревью, а не агент. У агента нет права записи в active.
