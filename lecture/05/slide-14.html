Session, State и Memory

Так эти понятия называет Google ADK. В других фреймворках имена другие, а смысл тот же.

Session

Одна нить разговора

События этого разговора: сообщения и действия.

State

Данные этой нити

Временные данные, нужные только текущему разговору.

Memory

Поиск по прошлому

Хранилище, из которого достают сведения других разговоров.
