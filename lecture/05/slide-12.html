Session, State и Memory

Управление контекстом идёт через эти три понятия. Агенту нужно вспоминать предыдущие обмены, чтобы разговор оставался связным и естественным.

01

Session

Индивидуальная нить чата. Регистрирует сообщения и действия (Events) этого взаимодействия и временные данные (State), нужные этому разговору.

02

State

session.state — данные внутри Session. Они относятся только к текущей активной нити чата.

03

Memory

Поисковое хранилище сведений из разных прошлых чатов или внешних источников. Оттуда извлекают данные за пределами непосредственного разговора.

Каждое взаимодействие — своя нить. Агенту может понадобиться доступ к данным более ранних взаимодействий.
