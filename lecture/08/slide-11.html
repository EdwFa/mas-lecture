Код: подзапросы по схеме

import json
from jsonschema import validate

PLAN = {"type": "object", "required": ["subqueries"],
        "properties": {"subqueries": {
            "type": "array", "minItems": 1, "maxItems": 4,
            "items": {"type": "object",
                      "required": ["q", "source"],
                      "properties": {
                          "q": {"type": "string", "maxLength": 200},
                          "source": {"enum": ["guidelines", "fhir"]}},
                      "additionalProperties": False}}}}

def plan_queries(question, llm):
    """Модель предлагает подзапросы, схема их ограничивает."""
    out = json.loads(llm(DECOMPOSE.format(question=question)))
    validate(out, PLAN)
    return out["subqueries"]
Схема

Фильтр, а не пожелание

Не больше четырёх подзапросов, источник только из двух. Лишнее поле — отказ.

source

Куда идти

guidelines — поиск по рекомендациям; fhir — запрос к карте через сервер из лекции 6.

Если не прошло

Запасной путь

Ошибка схемы — повтор один раз, затем поиск исходной фразой. Модуль не должен ломать весь конвейер.
