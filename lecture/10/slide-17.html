Шаг 0: реранкер и Platt

import numpy as np
from sentence_transformers import CrossEncoder
from sklearn.linear_model import LogisticRegression

reranker = CrossEncoder("BAAI/bge-reranker-v2-m3",
                        max_length=512)

def raw_scores(question, passages):
    p = reranker.predict([(question, x) for x in passages])
    p = np.clip(p, 1e-6, 1 - 1e-6)
    return np.log(p / (1 - p))          # логит пары

def fit_platt(scores, labels):          # σ(a·s + b)
    lr = LogisticRegression(C=1e6)
    lr.fit(np.reshape(scores, (-1, 1)), labels)
    return lr

def keep(question, passages, platt, threshold):
    s = raw_scores(question, passages).reshape(-1, 1)
    p = platt.predict_proba(s)[:, 1]
    return [(x, float(q)) for x, q in zip(passages, p)
            if q >= threshold]
Модель

Многоязычный реранкер

bge-reranker-v2-m3 читает вопрос и фрагмент вместе и работает с русским текстом локально.

Калибровка

Сдвиг и наклон

Platt подбирает a и b. Одной температуры мало: без сдвига b вероятность не сдвинуть к нулю.

Данные

300–1000 размеченных пар
