Сходство и softmax

Путь без обучения головы. У multilingual-e5-large-instruct вопрос начинается с Instruct и Query, фрагмент кодируется отдельно. Softmax на паре «сходство / минус сходство» даёт число от 0 до 1.

import numpy as np
from sentence_transformers import SentenceTransformer

model = SentenceTransformer(
    "intfloat/multilingual-e5-large-instruct"
)

def query_text(task, question):
    return f"Instruct: {task}\nQuery: {question}"

def softmax(scores, temperature):
    z = np.asarray(scores, dtype=float) / temperature
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

def yes_probability(question, passage, temperature=1.0):
    task = "Ответь, относится ли фрагмент к вопросу врача"
    vectors = model.encode(
        [query_text(task, question), passage],
        normalize_embeddings=True,
    )
    similarity = float(vectors[0] @ vectors[1])
    p = softmax([similarity, -similarity], temperature)
    return float(p[0])

Префикс query: / passage: у этой модели другой. Его подмена меняет вектор.
